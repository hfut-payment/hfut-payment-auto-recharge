# 自动充值

为宣城校区的常规电费、空调电费、洗浴和校园网设置自动充值。为每个项目单独设定低余额阈值和充值金额，任务满足条件后会尝试充值。

> [!IMPORTANT]
> **自动充值会实际扣款。** 启用前请逐项核对房间、手机号、充值金额与余额阈值。充值结果未确认时，先核对校方账单，再决定是否解除暂停。软件按现状提供，使用及核账责任以适用法律为准。

## 安装与启用

1. 确认 Android 宿主支持 HFP v2、校园费用充值权限和定时任务。先在宿主设置里配置宿舍或洗浴账号，并按宿主提示保存支付密码。
2. 在本仓库的 [Releases](../../releases) 下载 HFP，从宿主的插件管理导入，查看并授权所需能力。
3. 在插件设置或费用详情的「更多服务」进入对应项目。填写阈值、金额和校园卡最低保留余额，检查预览后授权启用。更换项目或升级规则格式后，重新确认授权。
4. 需要暂停时，关闭对应规则。显示「充值结果未确认」时，按页内提示核对账单。

任务约每 15 分钟判断一次。电费只在北京时间 06:00 至 23:00 前自动充值。洗浴和校园网可全天判断，已知失败后等待至少 1 小时。金额与支出上限同时受宿主的支付校验约束。

## 从源码打包

需要 Node.js 22.2 或更新版本。本仓库含插件源码和打包脚本。

~~~sh
node scripts/pack.mjs --source hfp --key /path/to/private.pem --cert /path/to/certificate.pem
~~~

产物位于 dist。覆盖升级需使用原发布证书。使用其他签名构建的包，能否使用扣款能力取决于宿主信任策略。
